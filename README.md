# 🎮 Godot — Trabalho II

Projeto desenvolvido como parte da disciplina **DCC148 – Desenvolvimento de Jogos**, utilizando a Godot Engine.

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de um jogo utilizando a Godot Engine, explorando diferentes recursos da engine e conceitos de desenvolvimento de jogos, como movimentação, combate, gerenciamento de armas, inteligência artificial, navegação, diálogos e elementos audiovisuais.

O trabalho consiste num jogo que segue os moldes de Hotline Miami 1 e 2, e segue tambem as especificaçoes do projeto, como menu, creditos, fases com objetivos, uso de animaçoes tileset e etc...

## 🕹️ Controles

| Tecla / Botão | Ação |
|:---:|---|
| **W** | Movimentar para cima |
| **A** | Movimentar para a esquerda |
| **S** | Movimentar para baixo |
| **D** | Movimentar para a direita |
| **Botão esquerdo do mouse** | Atirar |
| **Botão esquerdo do mouse** | Pegar armas do chão |
| **Clique fora da caixa de diálogo** | Avançar as falas |
| **R** | Reiniciar a fase |

## ⚙️ Tecnologias Utilizadas

- **Godot Engine** — Engine utilizada para desenvolvimento do jogo.
- **GDScript** — Linguagem de programação utilizada na implementação dos sistemas.
- **Godot Resources** — Gerenciamento e organização de dados dos recursos do jogo.
